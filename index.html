Privacy & Security Details

Importer names, filer codes, broker names, broker notes, consignee information, physical addresses, contact phone numbers, emails, and all columns not strictly required by DutyBack are permanently dropped. Real entry numbers, PO numbers, and supplier names are replaced with locally generated tokens (e.g., ENT-001, SUPPLIER-001).
DutyBack only sees anonymized tokens (e.g., ENT-001), HTS Chapter 99 numbers (e.g., 9903.01.24), duty dollar amounts, liquidation statuses, and locally computed day counts (days since liquidation, days until CAPE deadline, days until protest deadline). Important notice: FAU's owlONE platform logs interactions under standard FAU IT and cloud policies, so we do not claim data inside the chat is never stored. The Privacy Shield ensures your proprietary customs identity never enters the chat in the first place.
Yes! Because this application contains zero external dependencies, CDN scripts, or remote web fonts, you can save the page to your local drive (File > Save Page As...) and double-click to open it offline with no internet connection (file://). It operates identically.
Any column not explicitly on DutyBack's strict allowlist is automatically discarded during parsing. The tool reports exactly which columns were dropped so you can verify that internal SKU numbers, margin notes, or supplier pricing were excluded.
The lookup table (dutyback-lookup-table.csv) maps each anonymized token (such as ENT-001) back to your real customs entry number. It is built strictly in your local browser memory from the session key and downloaded only if you choose. Keep this file private on your computer and never upload or paste it into a chat. When DutyBack recommends filing actions for specific tokens, use this file to match them with your records in ACE.
